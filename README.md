# HyperOS2 Launcher

Protótipo de launcher Android inspirado visualmente no HyperOS 2.

## Recursos iniciais
- Relógio e data na tela inicial
- Lista de aplicativos instalados com pesquisa
- Ícones e nomes dos aplicativos
- Alternância entre papéis de parede em gradiente
- Compilação automática de APK debug pelo GitHub Actions

## Compilar
O workflow **Build Android APK** gera o artefato `HyperOS2Launcher-debug`.

Este é um protótipo inicial; a aparência e os recursos serão refinados após testes no dispositivo.
